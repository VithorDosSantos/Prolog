CONSULTA 1: Descobrir filhos de Carlos
-----------------------------------------
Comando: ?- filho(X, carlos).

Esperado: O sistema retorna todos os filhos de Carlos
Respostas esperadas:
  X = joao ;
  X = maria .

Explicação: 
- Utiliza a Regra 1: filho(X, Y) :- pai(Y, X)
- Unifica com pai(carlos, joao) → X = joao
- Backtracking: Unifica com pai(carlos, maria) → X = maria
- Nenhum fato de mae(carlos, ...) existe
- Resultado: duas soluções

Conceitos demonstrados:
✓ Variáveis em consultas
✓ Unificação com fatos
✓ Backtracking entre alternativas


CONSULTA 2: Descobrir avós de Ana ⭐ (DEPENDE DE REGRA)
-----------------------------------------
Comando: ?- avo(X, ana).

Esperado: O sistema retorna todos os avós de Ana
Respostas esperadas:
  X = carlos ;
  X = luis .

Explicação:
- Consulta depende INTEIRAMENTE de regras, não de fatos diretos
- Não existe fato direto "avo(...)"
- Prolog deve aplicar Regra 2: avo(X, Z) :- pai(X, Y), pai(Y, Z)
- Busca: pai(?, Y) e pai(Y, ana)
- Encontra: pai(joao, ana) → Y = joao
- Busca: pai(X, joao) → Encontra pai(carlos, joao) → X = carlos (primeira solução)
- Backtracking: Encontra pai(luis, joao) → X = luis (segunda solução)
- Tenta próximas cláusulas de avo (com mae) mas não encontra (sofia é mãe mas 
  também não é avó direta em nossa base de fatos)

Conceitos demonstrados:
✓ Regras e deducção (inferência)
✓ Encadeamento de regras (cadeia de raciocínio)
✓ Unificação em múltiplos passos
✓ Backtracking entre soluções


CONSULTA 3: Descobrir irmãos de João
-----------------------------------------
Comando: ?- irmao(joao, X).

Esperado: O sistema retorna todos os irmãos de João
Respostas esperadas:
  X = maria .

Explicação:
- Utiliza Regra 3: irmao(X, Y) :- pai(P, X), pai(P, Y), X \= Y
- Busca: pai(P, joao) e pai(P, X) onde joao ≠ X
- Encontra: pai(carlos, joao) e pai(carlos, maria) → X = maria
- Verifica: joao \= maria → verdadeiro ✓
- Também encontra mae(teresa, joao) e mae(teresa, maria)
- Mesma resposta: X = maria
- Resultado: uma solução (maria é irmã de joão)

Conceitos demonstrados:
✓ Regras com múltiplas condições
✓ Operador de verificação (\=, "diferente")
✓ Backtracking entre cláusulas diferentes
✓ Eliminação de soluções duplicadas
